# Михалыч — Корпоративный чат-бот для MAX

Чат-бот «Михалыч» для мессенджера MAX (VK Teams Bot API). Автоматизирует внутренние процессы компании Онланта: поиск сотрудников, доступ к корпоративным ресурсам, информация об отпусках, пароли Wi-Fi и другие сервисные функции.

## Возможности

- **/start** — авторизация и приветственное сообщение
- **Поиск сотрудников** — поиск по фамилии с валидацией ввода
- **Ресурсы компании** — постраничный каталог корпоративных ссылок (5 на страницу)
- **Хочу в отпуск** — информация о порядке оформления отпуска
- **Показать пароль WI-FI** — актуальный пароль корпоративной сети
- **Руководителю** — подменю для руководителей (в разработке)
- **Экспресс-отчет по контрагенту** — отчёт по ИНН (в разработке)
- **Помощь СИБ / Загрузить тренировку / Пин-понг** — отложены (заглушки)

## Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка

Скопируйте `.env.example` в `.env` и укажите токен бота:

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```
MAX_BOT_TOKEN=ваш_токен_бота
```

### 3. Запуск

```bash
python run.py
```

### 4. Docker

```bash
docker build -t mikhalych-bot .
docker run -e MAX_BOT_TOKEN=ваш_токен_бота mikhalych-bot
```

## Тесты

```bash
pip install pytest
python -m pytest tests/ -v
```

## Конфигурация

| Переменная | Обязательная | Описание | По умолчанию |
|-----------|-------------|----------|-------------|
| `MAX_BOT_TOKEN` | Да | Токен бота MAX | — |
| `API_BASE_URL` | Нет | Базовый URL API | `https://api.max.ru/bot/v1` |
| `LOG_LEVEL` | Нет | Уровень логирования | `INFO` |
| `POLLING_INTERVAL` | Нет | Интервал опроса (сек) | `1` |
