# Telegram Bot для интеграции с системой Assyst

## Описание

Telegram-бот для приема обращений пользователей и интеграции с системой управления заявками Assyst. Обеспечивает полный цикл работы с заявками: от создания до закрытия с уведомлениями о всех изменениях статуса.

## Основные возможности

### Для пользователей

- 🔐 **Авторизация по email** с проверкой в системе Apex
- 📋 **Создание заявок** с описанием и вложениями (до 10 фото)
- 📊 **Просмотр списка заявок** через команду `/myrequests`
- 🔔 **Уведомления в реальном времени** об изменении статуса заявок
- ✅ **Согласование закрытия** заявок прямо в Telegram
- ⭐ **Оценка качества обслуживания** после закрытия заявки

### Для системы

- 🔄 **Двусторонняя синхронизация** с Assyst через webhook
- 📧 **Автоматическая отправка** заявок в Assyst по email
- 💾 **Хранение истории** всех заявок в локальной БД
- 🛡️ **Система ограничений** для предотвращения спама
- 📝 **Полное логирование** всех действий

## Архитектура

```
Telegram User ←→ Telegram Bot ←→ Apex (auth)
                       ↓
                   Local DB
                       ↓
                    Assyst (Service Desk)
```

## Технические требования

- Python 3.10+
- PostgreSQL 13+
- Redis (для кэширования и rate limiting)
- SMTP сервер для отправки email
- HTTPS endpoint для webhook от Assyst

## Основные команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Запуск бота и авторизация |
| `/myrequests` | Список всех моих заявок |
| `/cancel` | Отмена текущей операции |
| `/help` | Справка по использованию |

## Интеграция с Assyst

### Поддерживаемые события (webhook)

| Событие | Описание |
|---------|----------|
| `new` | Регистрация новой заявки |
| `clockstop` | Остановка таймера (переход в ожидание) |
| `clockstart` | Запуск таймера (возврат в работу) |
| `confirmation` | Запрос согласования закрытия |
| `closed` | Закрытие заявки с оценкой качества |

### Webhook Endpoint

```
POST /itsm-bot/webhook
Content-Type: application/json
```

## Система ограничений

Для предотвращения злоупотреблений реализованы следующие лимиты:

- ⏱️ **Интервал между заявками**: 15 минут
- 📊 **Максимум заявок в час**: 5
- 📅 **Максимум заявок в сутки**: 10
- 🔒 **Попытки ввода кода**: 3 (блокировка на 5 минут)
- 🔍 **Попытки поиска email**: 2

## Валидация данных

### Описание заявки

- Минимум: 20 символов
- Максимум: 1000 символов
- Запрещены повторяющиеся символы

### Файлы

- Форматы: JPEG, PNG, JPG
- Максимум файлов: 10
- Размер файла: до 10 МБ
